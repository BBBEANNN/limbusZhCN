# v1.5.3 Android 17 相容修復（測試版）

針對 Samsung SM-S9180 / Android 17（API 37）診斷中的啟動閃退，修復
VirtualApp 的 `IServiceConnection.connected(..., IBinderSession, boolean)` 回呼相容性。
依執行時介面偵測新版格式，保留 service 與 session Binder、元件及 dead 狀態，
並維持舊版 Android 的回呼路徑。

## 安裝

1. 下載並安裝 `LimbusZhCN-v1.5.3-android17.apk`。
2. 開啟「邊獄漢化 Android 17 修復版」，使用「啟動漢化版遊戲」。
3. 首次進入遊戲完成登入與資源下載後，返回漢化器再次啟動以建立漢化索引。

這是基於 BBBEANNN/limbusZhCN 的獨立社群構建，使用獨立包名
`com.example.limbuszhcn.android17` 與獨立簽名，**可以與原版並存**。
不需卸載原版，也不會覆蓋原版容器；新容器需準備自己的遊戲資源。
若原版已有可用資源，可在原版「高級設定」遷出，再於修復版遷入。
本分支的後續版本請從本倉庫 Releases 下載；應用內的自身更新功能仍採上游簽名政策。

## 驗證

- 131 項測試通過、3 項既有跳過，包含 6 項新增 Binder 相容回歸測試。
- 使用 JBR 21.0.9、SDK 35、NDK 30.0.14904198 完整編譯。
- APK v2 簽章、16 KiB ZIP／ELF 對齊、arm64-v8a 與獨立 Provider authorities 已核對。
- 測試用的隱藏介面類別未被打入 APK。
- APK SHA-256 請核對附件 `SHA256SUMS.txt`。

此環境未連接 Samsung / Android 17 真機，尚未驗證實際登入、遊戲資源下載與漢化顯示。
原診斷後續另有 SIGSEGV，需在修復最早的 Binder 致命錯誤後確認是否仍會重現。
