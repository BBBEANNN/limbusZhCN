# 战斗技能名字体调整

## 目标与边界

用户要求战斗中的技能名字面稍细、描边稍粗，技能效果说明保持原样。必须依据设备
运行时确认的组件身份限定范围，不能按中文内容、技能名字面、大字号或单行特征泛化。
全局中文材质继续使用 `_OutlineWidth=0.12`、`_FaceDilate=0.12`。

## 诊断与实现方法

- 沿用既有 `TMP_Text` 赋值 hook 和 IL2CPP 反射 getter，只采集有限的组件层级、
  字重、字体/材质对象与 SDF 参数，不输出文本正文或账号信息。
- 诊断通过临时 Android debug 属性开启，默认关闭，分批限制数量；晚进入战斗时
  可重新开启一批，避免标题页耗尽记录预算。
- 确认目标身份后，从中文字体自身材质建立专用战斗技能名材质，不继承日文图集。
  参数先设置再绑定，材质写入拦截须维持正确材质，组件复用时恢复原字体与材质。
- 优先小幅调整材质参数，不在缺证据时全局清除 TMP Bold 或修改字号。

## 验证计划

宿主单元测试、设备独立 native 回归、APK 签名与 16 KiB 对齐检查，以及同一战斗
画面前后对照。需额外检查技能效果说明、非战斗技能名及组件复用恢复。

## 初始设备证据

- ADB：`1e2d22ca`，`PHY110`，Android `16`；已安装汉化器 `1.5.2` / versionCode `8`。
- 已安装包证书 SHA-256 与本地交接签名一致，可进行保留数据的覆盖安装。
- 已运行现有设备独立 native 回归：77 项通过，尚未验证本次字体效果。
