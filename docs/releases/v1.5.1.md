# v1.5.1：自身更新与翻译匹配修复

本次正式版为 `1.5.1`（versionCode `7`），支持 Android 8.0 及以上、arm64 设备。

## 本次更新

- 每次打开或返回汉化器前台时检查官方 GitHub 稳定版，发现新版自动下载，校验完整性、版本和签名后交给 Android 确认安装。首次可能需要允许安装来源；取消后可手动重试，不会反复弹窗。检查失败不阻断启动游戏。
- 修复同一译文经过多层文本处理后被再次翻译、剧情或歌词片段误作短术语，以及无可靠标识记录按位置猜译的问题。索引升级为 schema 11，旧索引会按新规则重建；译名仍只来自公开汉化包。
- 修复中文黑边向内侵蚀细笔画的问题，保留原字体排版。底栏字体调整试验已撤回，本版没有新增导航字号或全局字重策略。
- 正式纳入资源迁出／迁入功能：通过系统文件选择器处理资源 ZIP，校验逐文件 SHA-256，支持取消、保留已有文件、失败回滚和中断恢复。资源包不含账号、PlayerPrefs 或游戏 APK。
- 修复 Android 8.0/8.1 内置 microG 签名读取及索引路径兼容，保留后续系统的完整性检查。

## 覆盖升级

本 APK 已核对与 **v1.4 正式版同签名**，也与本次手机实测的本地 1.5 构建同签名，可保留现有数据覆盖升级。不要清空容器或卸载游戏。

此前 GitHub 的 `v1.5-test-20261020` 预发布 APK 使用另一张证书，**不能直接覆盖该测试包**；请保留旧安装及资源，勿为升级直接卸载。自更新遇到签名不一致会停止，不会绕过系统校验。

汉化器 APK 更新与游戏汉化包更新独立。游戏仍需通过 Google Play 安装，汉化内容只从公开 GitHub Releases 获取。

## 验证与现有边界

- 宿主测试 121 项通过、3 项既有跳过；设备独立 native 回归 77 项通过。
- 194,787 条字段完成生产查找与连续三层、已知来源复制稳定性核对，未发现二次改写。
- PHY110 / Android 16 已进入容器游戏主页与人格编队页，确认 schema 11 接管和中文显示。发布 APK 原生库与该已验证构建逐字节一致；APK v2 签名及 16 KiB ZIP 对齐检查通过。
- 上游会员码 UI 仍有 15 条韩文目标，44 条无可靠配对记录保留原文；不据此猜译，也不承诺所有页面已逐项视觉验收。
- 应用内系统授权和自动升级完整流程、多 GB 资源迁移仍需继续实际使用验证。
